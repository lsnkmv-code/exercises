# Geometry CLI

Консольное приложение на Go для выполнения простых геометрических расчётов:

- расстояние между двумя точками;
- площадь и периметр окружности;
- площадь и периметр полигона;
- проверка принадлежности точки окружности или полигону.

## Требования

- Go 1.26 или новее.

## Сборка и запуск

Перейдите в каталог проекта и загрузите зависимости:

```bash
cd geometry
go mod download
```

Соберите исполняемый файл:

```bash
go build -o geometry-app ./cmd/app
```

После этого в текущем каталоге появится бинарник `geometry-app`. Общий формат
запуска:

```bash
./geometry-app [операция] [параметры]
```

Например:

```bash
./geometry-app --distance --point 0,0,3,4
```

В Windows соберите файл с расширением `.exe` и запускайте его из PowerShell:

```powershell
go build -o geometry-app.exe ./cmd/app
.\geometry-app.exe --distance --point 0,0,3,4
```

За один запуск можно указать только одну операцию: `--distance`, `--area`,
`--perimeter` или `--contains`.

Координаты передаются через запятую без пробелов. Каждая точка задаётся парой
`X,Y`.

## Примеры

### Расстояние между точками

Расстояние между `(0,0)` и `(3,4)`:

```bash
./geometry-app --distance --point 0,0,3,4
```

Результат:

```text
The distance is: 5.00
```

### Окружность

Окружность можно задать одним параметром `--circle X,Y,R`:

```bash
./geometry-app --area --circle 0,0,5
./geometry-app --perimeter --circle 0,0,5
```

Также центр и радиус можно передать отдельно:

```bash
./geometry-app --area --center 0,0 --radius 5
```

Проверка, находится ли точка `(3,4)` внутри окружности с центром `(0,0)` и
радиусом `5`:

```bash
./geometry-app --contains --point 3,4 --circle 0,0,5
```

Точка на границе окружности считается принадлежащей ей.

### Полигон

Для работы с полигоном добавьте флаг `--polygon`. После `--point` перечислите
координаты его вершин. Требуется не менее трёх вершин.

Площадь и периметр треугольника с вершинами `(0,0)`, `(4,0)` и `(4,3)`:

```bash
./geometry-app --area --polygon --point 0,0,4,0,4,3
./geometry-app --perimeter --polygon --point 0,0,4,0,4,3
```

При проверке принадлежности сначала передаются координаты проверяемой точки,
а затем вершины полигона. Например, точка `(2,1)` и тот же треугольник:

```bash
./geometry-app --contains --polygon --point 2,1,0,0,4,0,4,3
```

Точка на стороне или вершине полигона считается принадлежащей полигону.
Поддерживаются как выпуклые, так и вогнутые полигоны без самопересечений.

## Доступные флаги

| Флаг | Назначение |
| --- | --- |
| `--distance` | Рассчитать расстояние между двумя точками |
| `--area` | Рассчитать площадь фигуры |
| `--perimeter` | Рассчитать периметр фигуры |
| `--contains` | Проверить принадлежность точки фигуре |
| `--point` | Передать координаты точек |
| `--circle` | Задать окружность в формате `X,Y,R` |
| `--center` | Задать центр окружности в формате `X,Y` |
| `--radius` | Задать радиус окружности |
| `--polygon` | Указать, что операция выполняется над полигоном |

Справка по параметрам:

```bash
./geometry-app --help
```

Во время разработки приложение также можно запустить без предварительной
сборки командой `go run ./cmd/app`, но примеры выше используют собранный
бинарник.
